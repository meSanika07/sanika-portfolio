# Sanika Kundekar — Software Engineer Portfolio

A modern, responsive, recruiter-friendly personal portfolio website engineered with **Tailwind CSS**, clean semantic HTML5, and vanilla modern JavaScript (ES6+).

Live Website: [sanika-portfolio-iota.vercel.app](https://sanika-portfolio-iota.vercel.app/)

---

## 🌟 Key Features

- **Recruiter-First UX**: Fast scanability, academic stats, live opportunity availability badge, and quick access to resume, GitHub, and LinkedIn.
- **Tailwind CSS Architecture**: Clean utility classes, custom brand design system, and sleek dark/light mode surfaces.
- **Dark & Light Mode**: Seamless theme toggle with local storage persistence and system preference synchronization.
- **Categorized Project Showcase**: Interactive project filtering (Full-Stack, AI & ML, Systems & Tools) with live demo and GitHub source code links.
- **Technical Skills Matrix**: Comprehensive breakdown across Frontend, Backend & APIs, Cloud & DevOps, AI & Machine Learning, Databases, and Core CS Fundamentals.
- **Interactive Certificate Modal**: Recruiter lightbox modal allowing in-page inspection of certificates (AWS, Postman, Super 30) and IEEE publication links.
- **1-Click Copy Email**: Quick copy button with toast notification for effortless outreach.
- **Interactive Contact Form**: Client-side validation with status feedback and native mail client fallback.
- **Responsive & Accessible**: Mobile-first design with accessible navigation drawer, ARIA attributes, and smooth scrollspy.

---

## 🛠️ Tech Stack

- **Styling**: Tailwind CSS (Play CDN & Custom Utility Tokens)
- **Markup**: Semantic HTML5, accessible SVG icons
- **Logic**: Vanilla ES6+ JavaScript (Zero heavyweight dependencies)
- **Typography**: Inter, Plus Jakarta Sans, JetBrains Mono
- **Deployment**: Vercel / GitHub Pages (Static Hosting)

## 🚀 Local Development

You can run the portfolio locally using any of these simple methods:

### Method 1: NPM Start (Recommended)
```bash
npm start
```
Then open `http://localhost:8080` in your browser.

### Method 2: Direct Browser Open (No server needed)
Double-click `index.html` or open it with Chrome / Edge.

### Method 3: Live Server in VS Code
Right-click `index.html` in VS Code and select **"Open with Live Server"**.

### Tailwind Build & Watch:
```bash
# Rebuild CSS
npm run build

# Watch for real-time CSS updates while editing
npm run watch
```
